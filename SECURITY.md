# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via **GitHub → Security → Report a vulnerability** on this repository (GitHub Private Vulnerability Reporting). You'll get a response within a few days. Please don't open public issues for security reports.

## Security model

**Your API key**
- Stored at `~/.config/gmi/.env` with `0600` permissions via `gmi config set-key` (run it with no argument to be prompted — keeps the key out of shell history).
- Sent only to GMI Cloud endpoints (`console.gmicloud.ai`, `api.gmi-serving.com`) as a Bearer header. It is never logged, never included in error output, and never written anywhere else.
- MCP client configs generated by `gmi mcp-config` deliberately contain **no key** — the server loads it from the file above.

**Uploads are public**
- `gmi upload` (and the MCP `upload_file` tool) uploads to GMI's storage and returns a **public, unauthenticated URL**. Only upload media you're comfortable being fetchable by URL. Non-media file types are rejected before any network call.

**Agent/MCP surface**
- The MCP server runs with your local file permissions. An AI agent connected to it can read local media files (for upload) and write downloaded assets to disk. Review your agent's actions like you would any tool with file access. The server never executes shell commands from tool arguments; external converters (`sips`, `ffmpeg`) are invoked with fixed argument arrays (no shell interpolation).

**Network behavior**
- Requests go only to GMI Cloud, plus at most one request per day to `registry.npmjs.org` to check for updates (no telemetry, nothing sent but the package name; delete `~/.config/gmi/update-check.json` and it re-checks, or ignore it — a failed check is silent).
- Retries never re-submit paid generation jobs (429-only for POSTs).

**Hardening details**
- Downloaded filenames derived from server URLs are sanitized (no path separators, no leading dots) so a hostile response can't write outside the output directory.
- Presigned upload PUTs go to the exact URL GMI returns; nothing else is fetched from user input except URLs you explicitly pass.
- CI runs with `contents: read` permissions; releases publish with npm provenance.

## Supported versions

Only the latest release receives fixes. Run `gmi update` (or `npm install -g unofficial-gmi-cloud-cli@latest`) to stay current.
